Vehicle Hub Lite V5.8.8｜多裝置同步與資料核對版
================================================
保留淺色精簡介面、免登入、固定車輛識別列、加油/維修/油耗、工單附件、備份與 Google Sheets／Drive 雙向同步。沿用原 localStorage、IndexedDB、雲端配對及後端 API。公開包不含私人歷史資料、附件或金鑰。

這次更新
- 固定車輛列新增立即同步，不必切到資料管理。
- 資料管理顯示目前車輛本機／最近確認雲端版本的加油、維修與附件引用筆數，並比對目前車輛的有效紀錄內容；相同筆數但內容不同也標示差異。另顯示所有車輛的本機及最近確認版本筆數。最近確認版本不是即時讀取的雲端狀態，請參照同步狀態、版本與時間。
- 同步中再次觸發更新會排隊；表單導致暫緩時，結束或取消後自動續接。跨頁或切車前保護未儲存的表單，取消車輛設定後可續同步。
- 復原最近刪除紀錄只針對目前車輛；搜尋支援維修明細名稱、附件名稱與含千分位的數字。
- 保留 V5.8.5 IndexedDB 同步基準容量修正、V5.8.6 內建網址及 V5.8.7 搜尋防誤填。不改動歷史紀錄，不需要再輸入原本已配對的金鑰。

既有使用者升級（V5.8.4～5.8.7）
1. 手機與電腦分別匯出完整 JSON 備份，放在 GitHub 專案外。若有未同步的紀錄，保留各自備份。
2. 解壓本 ZIP，更新 GitHub 專案根目錄檔案，保留 .git 與自己的 Pages 部署設定。不要把私人 JSON、原始附件或配對金鑰上傳 GitHub。舊版公開提交若含私人資料，單純刪除工作目錄不能清除提交歷史。
3. Commit、Push 後重新整理網站，確認頁面顯示 V5.8.8。手機 PWA 若仍顯示舊版，關閉後重新開啟或重新整理；不要清除網站資料。
4. 點固定車輛列的「立即同步」，在資料管理核對版本、時間、兩台車的本機與最近確認筆數。舊配對與本機資料保存位置不變。不必重新部署 Apps Script，不必重新匯入歷史備份。
5. 若發生衝突，先備份並下載衝突報告，再選擇只對衝突採用哪一端；勿無條件覆蓋較新的紀錄。

新裝置／第一次部署
- 已部署 V5.8.4 Apps Script 的使用者：直接開啟本系統，在資料管理輸入相同私人配對金鑰。預設 /exec 網址已內建。原先配對的不同網址不會被強制改寫。
- 尚未部署：沿用 V5.8.4 後端包的 Code.gs 與部署說明，執行 setupVehicleHubLite，在原試算表中建立新版資料區。舊表保留，不自動搬入舊 SystemData。
- 新裝置空白時可由雲端下載。若雲端尚無資料，先確認第一台的最新本機資料與附件完整，再同步。必要時安全合併私人歷史備份（2026/11/18，101 筆加油、13 筆維修、158 項明細、10 份附件）；它不是最新雲端資料的保證。

同步與儲存注意事項
- 開啟、儲存後約 1.8 秒、重新連網、重回前景時觸發；前景每 60 秒核對。關閉或背景執行時不保證同步。
- 正在編輯時暫緩套用雲端資料。取消或儲存未完成表單後續接。其他分頁已更新時請重新整理，先保留未儲存內容。
- 不同紀錄可合併；同筆資料的不同修改、刪除與修改、疑似跨端重複須核對。雲端修訂版保護不變。
- Sheets 保存紀錄及明細；Drive 保存附件。單檔上限 15 MiB，支援 JPG/PNG/WEBP/GIF/PDF。缺少或損壞的附件會暫停完整同步；不要刪除附件來繞過驗證。附件筆數比較為引用數量，非每次重新檢查檔案內容。
- 主紀錄與本機復原點仍使用 localStorage；同步基準及附件使用 IndexedDB。儲存空間不足先備份，不要清除本站資料。後端保留歷史版本，紀錄 JSON 上限 150 萬字元；注意 Google 配額。
- 配對期間停用整份復原與清除全部資料；仍可匯出、安全合併、復原此車個別刪除紀錄。配對金鑰保存在裝置本機，持有者可存取家庭資料，不能公開。

上線驗收
以電腦、手機分別切換 VOLVO、LEXUS，確認各自加油、維修筆數及搜尋清單；電腦新增測試紀錄，手機點立即同步核對；反向修改、刪除及復原。開啟表單後嘗試離開頁面並取消/確認，核對同步恢復；測試附件預覽、離線更新及完整備份匯出。

測試範圍
本版 7 套 Node 程式測試全部通過（歷史備份、加油油耗、工單、車輛隔離、搜尋、附件、版本化雲端同步、IndexedDB 錯誤恢復、預設網址、新增筆數核對及續接、跨頁表單與此車復原）。測試使用 DOM/瀏覽器儲存及模擬雲端介面，非實際雲端連線。Chromium 測試開啟 localhost 被執行環境管理政策阻擋；未完成 GitHub Pages、實際 Google Apps Script、手機與 iPad PWA 的實機驗收。
