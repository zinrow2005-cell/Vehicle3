Vehicle Hub Lite V5.9.0｜維修工單影像辨識匯入版
=================================================
以 V5.8.8 為基礎，維持免登入、淺色界面、固定車輛識別、加油／維修／油耗、原有備份及自動雙向同步。公開網站包不含私人資料、附件或金鑰。不必重新匯入資料、不必清除本機儲存、不必重新配對（使用原部署 URL 時）。

【本次需一起更新 Apps Script】
1. 電腦與手機分別匯出完整備份，放在 GitHub 專案外。確認原有紀錄、附件及雲端同步狀態。
2. 使用另附的 VehicleHub_V5.9.0_Apps_Script.zip，備份原 Apps Script Code.gs，再替換新版 Code.gs。原試算表、LITE_* 屬性、附件資料夾不變。
3. 左側「服務」的 + 加入 Drive API v3（已加入則不必重複）。執行 authorizeVehicleHubOCR 並完成授權。若從未初始化才執行 setupVehicleHubLite；原使用者不用重新初始化或輪替金鑰。
4. 「部署 → 管理部署作業」→ 編輯原 Web App → 選新版本 → 部署。保留原 /exec 網址及原有權限設定（我／任何人，資料請求仍需私人配對金鑰）。不要建立新的資料庫或改動 LiteSyncDataV584。
5. 透過 GitHub Desktop 更新根目錄檔案，保留 .git 及自己的 Pages 配置；新增 ocr.js，更新 index.html/styles.css/app.js/cloud.js/sw.js 等。不要將後端包、私人資料或金鑰上傳到公開 GitHub。Push 後重新開啟網站／PWA，確認顯示 V5.9.0。

【辨識操作】
維修紀錄 → 影像辨識 → 拍攝工單或選圖片/PDF → 視需要旋轉 90°及加強對比 → 開始文字辨識 → 對照候選欄位及原圖 → 確認車輛並套入表單 → 手動更正 → 勾選已核對 → 儲存維修紀錄。儲存後延續原本的雲端同步機制。辨識過程不建立維修紀錄、不啟動自動 AI 請求；已套表結果需核對，若要重新辨識請取消新工單後再開啟。
- 一般辨識：使用 Google Drive OCR，免費額度／使用限制依 Google 帳戶，不需要 Gemini API 金鑰。Google Drive OCR 文件建議 2 MB 以下。照片可在瀏覽器旋轉、提高對比（依瀏覽器支援）及壓縮後傳送；不含自動裁邊或透視校正。保留原始影像（不以壓縮辨識版替代附件）。
- 一次上傳一份工單；JPEG/PNG/WEBP/GIF 照片轉成 JPEG 辨識；PDF 原檔傳送。附件上限 15 MiB，辨識上限 10 MiB；較大 PDF 建議先分割。HEIC 若不能轉成 JPG，請改用相容格式拍攝或轉檔。
- AI 進階辨識（選用）：設定 Gemini API 金鑰後可處理較複雜的表格和手寫內容；每次使用會請求確認傳送影像。可能產生 API 費用；含個資的工單不要使用不適合的免費方案（免費方案資料可能用於改善服務），建議核對 Google 隱私與付費條款。系統不自動啟用，不含任何 API 金鑰。詳見後端部署說明。
- 手動備援：可使用「只加入原始附件」並手動填表；可複製「ChatGPT 整理指令」，將照片傳給 ChatGPT 後把整理結果貼回辨識文字欄，再按「重新整理欄位」。貼文字不需要雲端配對。
- 欄位狀態為規則候選、待人工核對或未確定，非 OCR 引擎提供的百分比信心分數。未確定的進廠日期及實付金額不得空白儲存，里程可留空。車牌或車型命中其他已建車輛時阻止套入；無法確認車輛須人工核對。若金額有推算、單價×數量不符或工資/零件缺項，顯示提示，不自動修改原單實付。
- 儲存原始附件到既有 IndexedDB（配對後同步 Drive）；辨識文字/整理文字各保存最多 12,000 個字元，重複文字不另存，超出標記截短；原始檔始終為依據。維修清單可展開辨識原文。辨識文字跟紀錄一起同步，包含單據上可能出現的個資，請勿公開備份。
- OCR 需網路且完成私人配對；手動輸入與貼文解析可離線。錯誤可重試，不會修改現有紀錄。雲端不保證背景同步，關閉或取消表單後自動續接。維護原有版本衝突保護。不要清除瀏覽器資料。

【測試及限制】
8 套前端 Node 程式測試、2 套後端 Node 模擬測試，包含原始 7 套回歸與新增 OCR 專項；使用真實私人備份在本機測試（未包含在公開包）。原 2 車、101 加油、13 維修、158 明細、10 附件通過回歸檢查。以 LEXUS 估價單手工轉寫的文字測試規則可整理 10 項明細與 12,961 元實付，非影像 OCR 實測，無辨識率保證。新增測試使用合成資料避免公開個資。Chromium 本機測試超時，未完成真實瀏覽器／手機驗收；Google Drive OCR 與 Gemini API 端點僅模擬，須實際部署及授權後驗證。不支援批次多工單辨識或外部 AI 自動同步。
