Vehicle Hub Lite V5.8.3｜油耗、工單與安全備份版
=================================================
本版沿用 V5.8.2 的本機儲存鍵 vehiclehub_lite_v580，免登入，無 Google Sheets 或雲端同步。固定車輛識別列顯示車名、車牌（若有）、當前車輛筆數與最新已知里程／紀錄日期；加油、維修、分析及 CSV 一律只顯示目前車輛。

更新方式（GitHub Desktop）
1. 更新前，手機和電腦各自匯出 JSON，保留本機資料及舊系統原始完整備份。
2. 解壓縮 GitHub ZIP，把其中檔案替換原專案網站檔案（index.html 等應位於原專案根目錄）。不要刪除 .git；保留原本的 GitHub Pages 設定／部署工作流程。不要把私人 JSON 放進 GitHub 專案。
3. Commit / Push，等待 GitHub Pages 部署。更新網站及 PWA；如尚未顯示 V5.8.3，關閉重開或重新整理。勿清除網站資料，以免移除本機紀錄與附件。
4. 直接進入新版。相同網址、瀏覽器／PWA 的舊 Lite 資料會沿用；新裝置初次開啟是空白的「我的車輛」。
5. 「資料管理」選擇安全合併，匯入另附的 VehicleHub_V583_20261118_private.json（不可上傳 GitHub）。這份備份包含 2 台車、101 筆加油、13 筆維修、158 個明細項目及 10 個舊工單附件。匯入後在維修清單展開工單資訊，可下載附件。
6. 若合併顯示衝突，下載 JSON 衝突報告並比對；同 ID 不同內容或疑似重複時保留本機資料，不靜默取代。只有確認來源資料應完整取代目前資料後，才使用「完整還原」。不同裝置仍需各自匯入，不會自動同步。

日常功能
- 加油：顯示完整區間公里、累計油量、km/L、每公里油費。以相鄰有里程的加滿點為起訖，起點的油量不計，中間部分加油／缺里程的加滿油量一併累積，無有效油量或里程矛盾的區間不計。估算資訊保留。年度／月份油耗按區間結束日歸類；支出按實際加油日期統計。
- 維修：可留空里程，不自動填入歷史里程。逐項明細支援分類、數量、單價、實際小計、備註；點「依明細計算金額」可帶入零件、工資與實付。折扣模式有另扣／已扣／手動實付，原單實付金額不會在讀取時被重算。只有新增或修改項目時才會提示明細不符。
- 附件：單檔上限 15 MB、JPG/PNG/WEBP/GIF/PDF，使用 IndexedDB 儲存，不會上傳網站。JSON 匯出含附件內容；若有缺檔則阻止完整備份並提示。附件可下載檢視。目前移除或刪除附件後仍可能保留本機二進位檔，以支援復原；不是安全清除功能。瀏覽器刪除網站資料或儲存空間遭系統清理可能造成附件遺失，請定期匯出備份。
- 分析：最新 60 個完整油耗區間折線、最近三段加權平均、年度加油＋維修支出、月度油耗及支出；估算開關不影響實際支出。未加入維修前後因果比較，避免將季節、路況等差異解讀為維修效果。
- 資料：安全合併／完整還原、同日疑似重複提示、上一個本機資料版本復原、最近刪除紀錄復原、目前車輛 CSV 匯出（可用 Excel 開啟）。復原點存於同一瀏覽器，不取代外部備份。不同裝置不自動傳遞刪除動作；同裝置曾刪除的 ID 在合併時阻止復活。

測試範圍與限制
已執行 Node.js 語法檢查、DOM 模擬回歸、多車隔離／防誤植、真實備份數量與油耗、折扣計算、合併衝突及附件位元組往返測試（模擬附件儲存 adapter）。測試可用 Node 執行 tests/core-test.cjs 與 tests/v583-test.cjs，選填私人資料檔路徑，勿提交私有資料。Chromium 可啟動，但本機測試頁面受環境政策 ERR_BLOCKED_BY_ADMINISTRATOR 阻擋，未完成真實瀏覽器／IndexedDB、PWA、手機與 iPad 驗收。
