Vehicle Hub Lite V5.8.6｜內建雲端連線位置版
==================================================
本版保留 V5.8.3 的明亮介面、固定車輛識別列、加油/維修/油耗、工單附件及備份功能。原本本機儲存鍵與 IndexedDB 不變。未配對仍可直接進入、離線使用；配對後自動雙向同步所有車輛。

V5.8.4 已配對裝置升級：只要更新 GitHub 前端，不需更新 Apps Script、重設或重新配對。先匯出備份，更新後確認 V5.8.6，點立即同步。舊同步基準只有在 IndexedDB 完成寫入後才會移除，原始紀錄與附件鍵不變。若首次同步曾已送出至雲端，新版先下載核對，不強制再上傳。若出現衝突，先下載報告並核對，不任意選擇覆蓋。

V5.8.6：預設 Apps Script 網址直接寫入前端；新裝置只需要輸入私人配對金鑰。進階設定仍可修改網址，既有配對（包括不同網址）保留，不自動切換資料庫。金鑰不隨程式公開。本版不必更新後端。

部署與第一次同步
1. 在每台舊裝置分別匯出完整 JSON 備份，放在 GitHub 專案外。保留舊 Code.gs 及 Google Sheets 備份。
2. 依另附 Apps Script 後端包的部署說明，更新原本試算表的指令碼並執行 setupVehicleHubLite；記下 /exec 網址、LITE_PAIR_KEY。舊表保留，新版使用 LiteSyncDataV584，不會自動搬入舊 SystemData。
3. 本 ZIP 解壓至 GitHub 專案根目錄，先備份舊檔、刪除不再使用的舊登入及內建私人資料檔（不要刪 .git 或原 Pages 部署設定），再 Commit / Push。不把後端包、金鑰、私人 JSON、原單據放進公開專案。若舊提交曾含私人資料，刪除工作目錄檔案不會清除舊提交，須另外處理。
4. 使用原本網址開啟新版（確認 V5.8.6）；若 PWA 仍顯示舊版，關閉後重新開啟/重新整理，勿直接清除網站資料。
5. 第一台裝置：確認最新紀錄與附件齊全。若缺資料，先從「資料管理」安全合併 V5.8.3 私人備份（2026/11/18，101 筆加油、13 筆維修、10 份附件）。較新的本機資料不要被舊備份取代。再輸入私人配對金鑰（預設 /exec 網址已內建），等待顯示「已同步」。第一次 10 份附件可能需多次請求。
6. 第二台裝置：輸入相同金鑰配對（預設網址已內建）；若本機空白，會自動取得雲端資料。如果本機有不同歷史紀錄，先保留備份，查看衝突報告再決定。不要讓較舊裝置強制取代新資料。確認兩台車與附件均可查看。
7. 驗收：在電腦新增測試加油紀錄；手機前景按立即同步確認可見。手機修改、電腦同步核對。刪除測試紀錄，核對另一台。關閉網路新增後再恢復，確認同步。確認工單附件下載與備份匯出。

同步說明
- 打開網頁、儲存後約 1.8 秒排程、重回前景/連線時觸發；前景每 60 秒核對。背景或關閉 PWA 不保證同步。打開加油/維修編輯表單、未儲存車輛設定或匯入期間會暫緩；完成後按立即同步或等定期核對。
- 固定車輛列顯示同步狀態；資料管理顯示版本及最近確認時間。車輛選取、搜尋條件不隨雲端同步。資料全數跨車同步，畫面只顯示選取車輛。
- 依共同版本三方合併，不同紀錄可自動合併；同筆修改不同、刪除與修改衝突或跨端疑似重複時暫停。可下載衝突報告，確認後只選擇衝突採用本機或雲端，非整份覆蓋。若變更再發生，需重新確認。無法判定車輛歸屬的衝突不提供強制合併。
- Google Sheets 保存版本化紀錄及工單明細；Google Drive 保存附件二進位檔。附件單檔上限 15 MiB，支援 JPG/PNG/WEBP/GIF/PDF。附件 ID 相同內容不同會停止同步。刪除紀錄可復原，附件與歷史版本不自動永久刪除。Sheets 歷史版本目前採保留策略，注意儲存空間和 Google 配額；紀錄 JSON 上限 150 萬字元。
- 整份復原/清空全部資料配對期間暫停，避免誤刪雲端。仍可安全合併/匯出/復原個別刪除紀錄。若另一個分頁已更新，重新整理再操作。
- 配對金鑰是存取權限（非公開資訊），保存在裝置本機瀏覽器，不含於備份。持有金鑰者可讀寫家庭資料；勿共用於不可信任裝置/網站。可由管理者輪替金鑰並在各裝置重新配對。

測試範圍
已通過 Node 語法檢查、V5.8.3 回歸、真實備份 101/13/158/10、兩個模擬裝置雙向同步、衝突/離線刪除復原，以及 10 份真實附件內容往返（IndexedDB/Drive 模擬 adapter）。後端 Google API mock 也通過金鑰驗證、版本競爭、Sheets 分段與校驗、Drive 附件及破損拒絕覆寫。尚未在實際 GitHub Pages、Google Apps Script、Google Drive、瀏覽器 CORS、手機/iPad PWA 實機驗收；必須依上方驗收流程完成。程式測試不是雲端連線成功的保證。

V5.8.5 專項測試：模擬 V5.8.4 在雲端已提交後 localStorage 同步基準寫入超額、新版再次核對不重送、重新開啟恢復基準、舊基準遷移失敗保留並重試、拒絕較舊基準覆蓋。原加油/維修資料、本機復原點、配對金鑰及附件資料庫均保持原儲存鍵。主資料與復原點仍使用 localStorage；若其他儲存鍵也不足，需另外處理，不要任意清理網站資料。新版基準改用獨立 IndexedDB，未修改後端 API 或試算表。專項測試為程式模擬，未實測使用者裝置或 Google 雲端。

V5.8.6 測試：預設網址、僅輸入配對金鑰、既有配對保留、進階網址修改及錯誤金鑰攔截的模擬測試通過；原 5 項測試套件（含真實備份資料、同步及容量修正）皆通過。未連線實際 Apps Script 或使用者裝置。
