為什麼需要Google Sheets＋Apps Script？

GitHub Pages只負責顯示網頁；瀏覽器本機資料不會自動跨電腦或手機同步。

Google Sheet保存家庭共用的車輛資料、可閱讀資料表與同步版本。
Apps Script負責登入驗證、讀寫資料、衝突鎖定與操作紀錄，不讓前端直接取得試算表權限。
GitHub Pages部署PWA介面與程式更新；不應在公開原始碼內放完整私人車輛資料。
安全提醒：正式啟用 Google Sheet 後，請在 Apps Script 管理帳號密碼；系統畫面不會顯示預設帳號或密碼提示。
